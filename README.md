# 🧠 Parkinson’s Disease Prediction using Machine Learning

This project focuses on predicting the presence of Parkinson’s Disease in patients using a supervised machine learning model. It uses biomedical voice measurements and applies classification algorithms to detect early onset.

## 🚀 Features

- 📊 Data loading & preprocessing
- 🔍 Feature selection & scaling
- 🤖 Model training using Support Vector Machine (SVM)
- 📈 Performance evaluation with accuracy, confusion matrix, and classification report
- 📉 Visualization of important metrics

## 🛠️ Tech Stack

- Python 3.x
- scikit-learn
- pandas
- numpy
- matplotlib / seaborn

## 📦 Installation & Setup

```bash
git clone https://github.com/RojaSriTallapragada/Parkinson-s-disease-prediction.git
cd Parkinson-s-disease-prediction
pip install -r requirements.txt
python parkinsons_prediction.py
```
## 📁 Dataset
UCI Parkinson’s Disease Dataset

## 📊 Results
Accuracy: ~92% using SVM

Confusion Matrix and classification report included
